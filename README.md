Калькулятор «Предварительный расчёт стоимости»
Копия конструктора glass-ter.ru/#constructor

Файлы
-----
index.html  — страница калькулятора
custom.js   — ставки, лимиты, списки, тексты (правьте здесь)
calc.js     — логика расчёта + UI, с комментариями
calc.css    — стили отображения

Как открыть
-----------
Откройте index.html в браузере. Сервер не нужен.
Либо положите папку на любой статический хостинг.

Как считается цена
------------------
Площадь м² = длина_мм × высота_мм / 1 000 000
Ориентир   = площадь × BASE_RATE_RUB (26 000 ₽)

Если форма «сложная / радиус» или высота > 3 000 мм —
цена скрывается: «Оценим по фото или плану».

Рекомендация системы
--------------------
7T  — прямой проём, высота ≤ 2 800 мм, есть парковка,
      сценарий «полностью открывать проём».
Coupe — все остальные рабочие случаи.

Тип стекла, сетка-плиссе и услуги на ориентир не влияют.

Проверка
--------
По умолчанию: 4 200 × 2 400 мм → 10,08 м² → 262 080 ₽
Пример с сайта: 6 000 × 2 400 мм → 14,4 м² → 374 400 ₽
(на сайте округляют до «от 375 000 ₽»).
